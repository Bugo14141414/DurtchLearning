# Dutch Learning

A personal, phone-only app for learning Belgian Dutch through everyday situations
(work at the kassa and in the kitchen, shops, restaurants, the doctor, city hall…).

**Open it on your phone:** https://bugo14141414.github.io/DurtchLearning/
then use *Add to Home Screen* — it works offline after the first visit.

- 21 situations, 524 phrases and words (`data.js`)
- 8 levels per situation, 90% to pass: multiple choice → listening → word building →
  writing → dictation → speaking → mixed master test
- Spaced-repetition flashcards, XP, daily goal and streaks
- Progress is stored on the phone; use *Cards → Backup* to export it

No build step: plain HTML/CSS/JS. Every push to `main` is published automatically.
